# Hasta Güvenliği Çarkı

Hasta güvenliği eğitimlerinde bilgi düzeyini ölçmek için hazırlanmış çark oyunu.

- Eğitim bilgileri ve katılımcı sayısı girilir, çark çevrilir (Boşluk tuşu), sorular cevaplanır.
- Sonunda eğitim etkinliği raporu çıkar: başarı oranı, soru ve katılımcı bazlı sonuçlar, ön test / son test karşılaştırması.
- Rapor yazdırılabilir, PDF olarak kaydedilebilir ya da Excel'e (CSV) aktarılabilir.

Tek dosyadan oluşur (`index.html`), internet bağlantısı veya kurulum gerektirmez.
Oturum kayıtları yalnızca oyunun açıldığı tarayıcıda saklanır.
